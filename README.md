
# GestionStock

Sistema web local para la gestión y control de inventario.

## Descripción

GestionStock es una aplicación desarrollada en PHP y MySQL que permite administrar productos y controlar diferentes movimientos relacionados con el inventario.

## Funcionalidades

- Inicio de sesión
- Dashboard
- Registro de productos
- Edición de productos
- Eliminación de productos
- Gestión de inventario
- Entradas y salidas de productos
- Historial de movimientos
- Validación de datos
- Pruebas unitarias

## Tecnologías

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- PHPUnit 9.6

## Pruebas unitarias

Se implementaron tres pruebas unitarias:

1. Validación del precio.
2. Validación del stock.
3. Validación de salida de inventario.

Las pruebas automatizadas comprobaron seis escenarios y obtuvieron un resultado satisfactorio:

**6 tests / 6 assertions**
